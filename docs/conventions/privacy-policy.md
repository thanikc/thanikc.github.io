# Privacy policy upkeep

`apps/ui/src/app/domains/privacy/privacy-policy.component.html` is a factual inventory (storage keys like `cookie-consent`, third-party processors, legal bases).

Any change that adds, removes or repurposes a cookie or storage key, makes a request to a new third party, or adds a new data-processing category must update it (plus de/th translations; see [i18n](i18n.md)).

Pure styling/refactor changes are exempt — but check first.
