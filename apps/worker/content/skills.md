# Skills

Thanik Cheowtirakul is a full-stack engineer whose core technical stack spans the
Angular front end, Spring Boot on the back end, and OpenShift and Kubernetes for
deployment.

## Frontend

Thanik builds front ends with **Angular**, using modern Angular patterns such as
standalone components, Signals, and `inject()`. He also works with TypeScript,
Angular Material, and Tailwind CSS.

## Backend

On the server side, Thanik develops microservices with **Spring Boot** and Java,
exposing REST APIs and handling persistence, security, and service-to-service
communication.

## Cloud and DevOps

Thanik deploys and operates applications on **OpenShift** and **Kubernetes**,
working with containers, Helm, and CI/CD pipelines. He is comfortable owning a
service from code through to running it in a container platform.

## Testing

Thanik writes end-to-end tests with **Playwright** and follows a test-driven
development workflow, treating tests as a first-class part of delivery.

## Ways of working

Thanik works in agile teams using **Scrum** and **Kanban**, and uses **Git** for
version control. He practices **AI-assisted development**: large language model
assistants are part of his day-to-day workflow for scaffolding tests, reviewing
architecture decisions, and speeding up routine implementation work.
